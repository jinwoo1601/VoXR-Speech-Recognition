## Contracts and interfaces

- **Reader.** `const string Accepted = "RIFF WAV, PCM 16-bit or float 32-bit, 1 or 2 channels, any rate"`. `AddOn` {`Path`, `Name` (root-relative, `/`), `Rate`, `Channels`, `Float`, `Data` (offset), `Frames`}. `static AddOn Header(string root, string name)`: walks chunks, word-aligned, unknown ones skipped; tag 1 needs 16 bits, tag 3 needs 32; `0xFFFE` (EXTENSIBLE) is read as tag 1 or 3 when `fmt ` ≥ 40 bytes and the SubFormat is the PCM or IEEE-float GUID (`0x0001`/`0x0003` then `00 00 00 00 10 00 80 00 00 AA 00 38 9B 71`), else refused. Any rate > 0. Refusals: `condition: <root>/<name>: cannot be read: <reason>; accepted: <Accepted>`, exit 2, where `<reason>` is one of `not a RIFF WAVE file`, `no fmt chunk before the data chunk`, `no data chunk`, `format tag 0x<x4>`, `PCM <b>-bit`, `float <b>-bit`, `<c> channels`, `rate <r>`, `block align <a>`, `data chunk past the end of the file`, `no samples`. `static double[] Frames(AddOn a, long start, long count)`: 16-bit `v / 32768.0`, float as is, stereo `0.5 * (l + r)`. `ReadPcm` and its callers are unchanged.
- **Folders.** `AddOns` {`Musan`, `Slr28`, `Game` (`List<AddOn>`, null when absent), `Responses` (`Dictionary` by `Name`, used only for lookups)}. `static List<AddOn> Folder(string root, string top, string sub, bool wavOnly)`: no `root/top` gives null (the generated or synthetic kind); otherwise every file under `root/sub`, recursively. With `wavOnly` set, only the extension `.wav` (ordinal-ignore-case) is kept, and `*` is enumerated so the 8.3 match never applies. Files are sorted ordinal by `Name`, and `Header` reads each one. None found (a missing `sub` counts as none) stops: `condition: <root>/<sub>: no file to read; accepted: <Accepted>`. The calls are (`musan`, `musan/noise`, true), (`slr28`, `slr28/RIRS_NOISES/simulated_rirs/smallroom`, true) and (`game-audio`, `game-audio`, false), made after `TruthCheck` on the negatives and before any case audio is read.
- **Rate conversion.** Lengths, frame counts and offsets are `long`; `len`, rates and `num`/`den` are `int`. `static long Scale(long x, int num, int den) => (2L * den * x + num) / (2L * num)` (20 s at 44.1 kHz is `2·48000·882000`, past `int`). `Resample(double[] input, int num, int den)` holds today's body with `f == 10` → `num == den`, `Scale(input.Length, f)` → `Scale(input.Length, num, den)`, `10.0 / f` → `(double)den / num`, and `(double)(k * f) / 10` → `(double)((long)k * num) / den`, `k` the `int` output index: in `long`, `k * f` keeps the value `int` gave, so `Resample(input, f) => Resample(input, f, 10)` is bit-identical on the speed path. A file goes `Resample(x, a.Rate, Rate)`.
- **Windows (MUSAN, game).** `static long Need(int len, int rate) => ((long)len * rate + 47999) / 48000` source frames. `static double[] Window(Rng pick, Rng at, List<AddOn> files, int len, spans, string clip, string folder, out string name, out long offset)`, `folder` being `<root>/<sub>`: every file serves (F11 "any audio file", :74 "any accepted file"). The file is `floor(pick.Uniform() × files.Count)`; with `m = Need(len, file.Rate)`, the offset is `floor(at.Uniform() × (Frames ≥ m ? Frames − m + 1 : Frames))`, and `m` frames are read cyclically from it (frame `(offset + i) mod Frames`): a file at least as long never wraps, a shorter one is tiled from a drawn phase. They are resampled, cut to the first `len` and filtered. With `e` the sum of squares over `spans` (the segments `Mix` sums over; null = the whole window, as `Rms(n)` is), while `!double.IsFinite(len / e)` (no signal, so `Mix`'s `a` or the twin's `k` would be inf/NaN, §6) file and offset are drawn again from the same two streams, at most `MaxDraws` (100) draws, then `condition: clip "<clip>": no window with signal under <folder> in 100 draws`, exit 2. A first draw with signal consumes nothing more. `static double[] Interferer(seed, clip, step, len, spans, AddOns a, out string file, out long offset)` returns the filtered interferer: on a game step, `Window` with tags `game-file`, `game-offset` over `game-audio`; else, with MUSAN present, tags `musan-file`, `musan-offset` over `musan/noise`; else `Filter(Pink(new Rng(seed, clip, step.Id, "noise"), len))` as today, with file null. It replaces the two `Filter(Pink(...))` expressions (:578 `s1.Length`, the speech segments; :636 `partner.Y.Length`, null). Existing tags and draws are unchanged: no key changes (toys 1–6, V5).
- **SLR28.** `RoomFor(seed, clip, step, a)` → (`H`, `T`, `Draws`, `Rt60`, `Response`). With no SLR28 it returns `Room(new Rng(seed, clip, step.Id, "room"), clip)` and Response null. Otherwise, from `new Rng(seed, clip, step.Id, "response")`, it draws `floor(u × n)` and measures the file once, caching the result: `Frames` all, `Resample` to 48 kHz, trimmed to start at the first index of max `|h|`, divided by that sample (`H[0] == 1`), then `Rt60` (unchanged). A file is taken when `static bool Eligible(double rt60) => !double.IsNaN(rt60) && rt60 >= Rt60Min && rt60 <= Rt60Max` (an empty fit window gives NaN); `Room`'s own acceptance (:306-308) is untouched. Otherwise the draw is repeated. When every file has been seen ineligible: `condition: <root>/slr28/RIRS_NOISES/simulated_rirs/smallroom: no response measuring 0.2–0.5 s (<n> files); accepted: <Accepted>` (:74 "naming it and the accepted formats"). For a file, `T` is 0, `Draws` counts the draws taken, and `Response` is its `Name`.
