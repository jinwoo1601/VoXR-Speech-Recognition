**Shapes.** (a): every required element spoken, required slots filled with a fixed valid value, optionals omitted, the target slot omitted. ## The arms

- **A0** — the staged parser, unmodified.
- **A4** — a missed required slot whose name is in F (an *exempt* slot), five points:
  1. contributes 0 to raw and 0 to den;
  2. is **not** counted in `missedRequired` (so DR-7 admission and the start probe stop seeing it);
  3. sets the leading-miss latch exactly as today;
  4. still marks the candidate slot-incomplete, so eager refuses it;
  5. is counted in `ExemptedSlots`, a new selection key placed immediately after score: fewer ranks better.
  Unchanged in every arm: an exempt miss still increments `requiredAfterLastMatch`, the selector for the forced orphan table. Not patched in any arm: the Editor-only runner-up `CompareCandidate` call and `ScoreFollowUp`.
- **A4-noTB** — A4 without point 5's key.
- **A4L** — A4 without point 2: the exempt miss **still increments `missedRequired`**, so DR-7 admission and the admissibility start probe see exactly what A0 sees.
- **A4L-noTB** — A4L without the key.

## Surprises (arm A4, against the change's stated intent)

1. **Point 2 loosens DR-7 admission enough to let fragments win round 1 on the start key.** A stutter fragment such as `launch` (1 matched, 1 missed) is admitted and outranks the real command starting one word later: DocCheck `'launch launch all missiles target hotel one'` goes from 0.833 with all slots to **0.333 with no slots**, the real command evicted from a one-entry result buffer; in Set_Combat `launch launch jackal track one three five seven` gives a 0.333 fragment round then the real command at 1.000 (A0 0.800). The four DocCheck failures: `target disengage` cease_fire 0.500 → **1.000**; `fire at` against `fire at {target}` 0.333 → **1.000**; §7 A start 2 0.167 → 0.400; `launch launch...` 0.833 → 0.333.
2. **Shape (a) scores exactly 1.000 on every pattern, including D = 2**, so bare verbs fire. The bar protects only against a missing *first* element; a verb followed by an exempt slot is never barred.
3. **The tie-break is load-bearing and cuts both ways** — the five sibling utterances above without it; the barred-candidate hand-off with it (Question 3).
4. **Cross-intent ambiguity under F = all is settled by registration order** (`orient to` / `orient two`).
5. **The D ≥ 4 threshold has no slack** (shape-(b) section).
6. **`requiredAfterLastMatch` left incremented on an exempt miss** keeps the forced orphan table: `drive cut drive` scores set_burn#0 at 1/3, not 1.0, and set_burn#1 (barred) wins round 1. Clearing it would change coverage grammar-wide; the report leaves the choice to the design.
7. **CIC and TacticalMap cannot build a parser** (*Scenes*).
