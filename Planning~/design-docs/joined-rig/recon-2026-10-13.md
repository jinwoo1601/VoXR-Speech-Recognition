# Recon: the joined-rig instruments and the dump feasibility probe, 2026-10-13

Transcribed from the code-mapper recon of 2026-10-13 and from probe 1 of lab `lab-next-level-probes`, both on branch `design-joined-rig`. The recon and the lab measure and decide nothing; every fact below is theirs, and none is recomputed here.

## The instruments' facts (code-mapper recon)

- **The harness** is `NativeBridge~/harness/main.cpp`.
  - It replays 48 kHz WAVs through the native pipeline: ring buffer → downsampler → AGC → int16 → VOSK (`NativeBridge~/src/vosk_bridge.cpp:91-126`).
  - It keeps only the final `text` (`main.cpp:41-58`) and passes on exact equality with `expectations.json` `expectedFinals` (`:227`).
- **Which pipeline ships where.** Quest and Android run that native pipeline. The Windows Editor runs its own managed C# pipeline, whose AGC has diverged from the native one (`Documentation~/native-bridge.md:61`; `01-code-audit.md:497`).
- **The parser rig** is `Planning~/features/coverage-in-selection/ab-rig/`.
  - It compiles the real parser source from any git ref under dotnet in WSL (`stage.sh:15-25`).
  - It reads text only; no words or confidences are passed (`Program.cs:304`).
  - It has no scorer.
  - Its grammar is a hand copy of the demo grammar. It is checked against the harness grammar pin by `--grammar` (`Program.cs:6-9`).
- **The only intent/slot check** is `Runtime/Testing/VoxrBatchTestRunner.cs`.
  - Intent and slots must match exactly, and the first failure ends the check (`:208`, `:303-329`).
  - The research's citation `:230-233` is a comment, not the comparison.
- **The recogniser decides what a player gets.** `Runtime/Commands/VoxrCommandRecogniser.cs` is a 2,072-line `MonoBehaviour` driven by `Time.time`. It owns the buffer window (split-utterance merging), eager flush, pending follow-ups and cooldown.
- **The fixtures** are 16 cases (`Tests~/Fixtures/audio/manifest.json`): clean 8, homophone 2, slot-variant 3, filler 1, split 1, silence 1. The split case expects one command across two finals.

- **The build.** The `desktop-linux` preset, in a WSL copy of `NativeBridge~`.
