### AGC (C++ `NativeBridge~/src/agc.h`, C# `Runtime/Dsp/Agc.cs`)

### R14 filter

- Defect: 15-tap filter is "a 3 kHz shelf" (R4:128-130): −3.3 dB @3 kHz, −6.1 @4, −16.0 @6, −25.9 @7, −36.7 @7.5 kHz; +2.51 dB DC; ~29 dB alias rejection (04:32; 03:62-67, measured twice). Model `mfcc.conf` uses to 7.6 kHz (R4:132-135). Link to `cease fire→safe five`, `all→fall` is a hypothesis (R4:139-140; 03:71).
- Proposed: 95-tap Kaiser fc 7800 Hz β 8.5, DC normalised: −0.36 dB passband edge, −53.9 dB alias, 1.52 MMAC/s, group delay 0.98 ms (R4:157-162; I1:23). Drop-in table + longer history (R4:148-149). APK 0 (I1:31).
- Kill: command-level accuracy does not improve or regresses at equal thresholds after a threshold re-sweep (I1:33; 03:236).
- Risk: every score shifts; `minScore` 0.6 / `minConfidence` 0.4 / leading-miss bar tuned to old tilt must be re-validated; normalise filter and re-check AGC target together (R4:164-167).

### R15 AGC

- Defect: kNoiseFloor 1e-5 below any real mic floor → gain → 20× in pauses (10× at 193 ms, 19× at 883 ms); post-pause cough ~26 dB hotter than speech (R4:634-638; 03:83). Unmeasured on VoXR (R4:644-645). −18 dBFS on mean-abs is aggressive → tanh compresses every syllable (R4:647-653). Onset overshoot ~20–30 ms (R4:660-664; hypothesis).
- AGC should be "a slow, speech-gated, utterance-level normaliser, not a per-sample compressor with a 10 ms attack" (R4:678-681). Keep the bounded-output → int16-cannot-overflow property (R4:706-707).
- Divergence: on digital silence C# freezes gain at once; C++ keeps adapting ~1.9 s toward 20× (03:85). Fixture corpus built from digital silence (`Tests~/Fixtures/generate.py:28-29`). "Until they agree, R14's A/B, R16's first-word-retention test and R4's silence-then-cough fixtures all measure a signal the device never sees" (03:234).
- Kill (gate half): silence-then-command fixtures show first-word retention dropping at any false-trigger reduction (I1:55; 03:234).
- Cheapest exp: diff post-AGC samples C++ harness vs C# Editor path (03:234). Silence-then-cough WAVs need human room-tone recordings (I1:57).
- `micGainTargetDb` migration hazard: meaning changes if statistic changes; `[FormerlySerializedAs]` does not migrate prefab-instance overrides (I1:59).
- Cost: 1–2 weeks + ~1–2 MB BSD-3 dependency for AGC2 (I1:53).

## WebRTC APM research

Researcher, 2026-11-05, PARTIAL; condensed by the PM.

Blocked: gitlab/cgit/lists.freedesktop.org (Anubis/503/403). Fork sources read via docs.rs mirror of crate webrtc-audio-processing-sys 2.0.2 (vendored tree reads version 2.1). WebRTC side from webrtc.googlesource.com main.

- Forms: freedesktop `webrtc-audio-processing` 2.1 (2025-01-22; 2.0 = WebRTC M131), meson only, "tested on Linux only"; C++17; Android defines present (no evidence of NDK release testing); MSVC flags present (clean MSVC build unverified); abseil >= 20240722 via meson wrap subproject (download at configure, SHA-pinned). No maintained CMake port found. https://www.freedesktop.org/software/pulseaudio/webrtc-audio-processing/ ; https://docs.rs/crate/webrtc-audio-processing-sys/2.0.2/source/webrtc-audio-processing/meson.build
- Licence: WebRTC BSD-3 + PATENTS grant (terminates on patent litigation vs WebRTC). RNN VAD weights from rnnoise, BSD-3. pffft, abseil (Apache-2.0) not read from source. None found not licence-clean.
- AGC2 config (`api/audio/audio_processing.h`, main): GainController2{enabled; input_volume_controller{enabled=false}; adaptive_digital{enabled=false, headroom_db=5, max_gain_db=50, initial_gain_db=15, max_gain_change_db_per_second=6, max_output_noise_level_dbfs=-50}; fixed_digital{gain_db=0}}.
- Order (`gain_controller2.cc`): VAD speech probability → levels/noise → speech level estimator → saturation protector → adaptive digital → fixed gain → limiter (always constructed; hard clip at end → bounded output).
- Adaptive digital (`adaptive_digital_gain_controller.cc`): target gain = −(speech level + headroom) clamped [0, max_gain]; capped by max_output_noise_level − noise level; rate-limited per 10 ms; VAD gates gain INCREASES only (needs N consecutive confident frames); decreases ungated.
- Framing: 10 ms frames; rates 8–48 kHz; ProcessStream in 48k/out 16k → APM resamples (PushSincResampler, Blackman window, cutoff 0.9×Nyquist ≈ 7.2 kHz at 16k; response figures not found) and processes at 16k. AGC2 VAD resamples ch0 to 24 kHz internally. int16 and float interfaces.
- VAD probability: NOT exposed by the public AudioProcessing API (stats has only deprecated voice_detected). Internal `VoiceActivityDetectorWrapper::Analyze()` returns it (agc2 namespace, non-public).
- Size: no Android/AGC2-only figure. Whole 2.1 package x86_64 ~1.42 MB installed (CachyOS). RNN VAD weights embedded int8.
- CPU: RNN VAD ~195× realtime on Pixel 2 XL (2020 commit snippet) ≈ 0.5 % core (PM-side arithmetic by researcher). R4 figure whole APM ~1.3 % XR2 core derated.
- Users/pitfalls: PipeWire echo-cancel; .NET SoundFlow wrapper; no Unity/Quest user found. Abseil ODR/duplicate-symbol risk on Android (libwebrtc.a case); abseil version drift needed patches downstream.
- Open: MSVC + NDK build as-is; .so size; AGC2 speech-level estimator constants; VAD threshold value.
