# `g2-lite` — the tree path

The order `g2-lite`'s `## Workflow` steps run in where `trees` is filled; "the contract" is `.claude/references/core/trees-contract.md`.

## The tree path

Where `trees` is filled, as the contract reads it, the steps run in this order; each item names the `## Workflow` steps it runs.

1. **ROOT** — `.claude/references/core/gate-close.md` `### ROOT`.
2. **LANE through HARD STOP** — `## Workflow`'s LANE; then CLASS, PREFLIGHT, PRESENT, REVIEW, RESOLVE and HARD STOP, as written, in this tree. The lane prerequisite, LANE and CLASS read the hub's `memory/STATUS.md` line, by absolute path under the Hub path. PREFLIGHT's `budget` run, on prose and trivial, adds `--hub "<Hub path>"`. RESOLVE's `--status` and the dated notes (`memory/<YYYY-MM-DD>.md`) its human-only check reads are the hub's, by absolute path under the Hub path, and its word is one `scripts/hub.py write --root <hub> --message <file> --entry Current <branch> <file>` command. HARD STOP runs on a human class only, its word appended to the record as `.claude/references/core/gate-close.md` `### CATCH-UP` **The word** says; else CHANGELOG follows RESOLVE.
3. **CHANGELOG** — the CHANGELOG line of `## Workflow`'s CLOSE OUT, the PM checking it in on the branch, in this tree, per the `vc` binding's check-in procedure, with CLOSE OUT's word on a falsified product doc where there is one. CLOSE OUT's `memory/` record waits for RECORD, after the merge.
4. **CATCH-UP and TIER** — `.claude/references/core/gate-close.md` `### CATCH-UP`, with `<skill>` `g2-lite`, `<slug>` `<changeset>` and the main branch the target, on a human class and a close by class alike; then `.claude/references/core/gate-close.md` `### TIER`, where tier 3 on a close by class is HARD STOP as a human class, as that section says. Where the catch-up resolved a conflict, changing the branch's own content, and the class is not human, RESOLVE's read and its `close-class` run again at the head it leaves, before LIST, and that run's class is the one LIST and MERGE read: a human class is HARD STOP, put as `### TIER` puts it at tier 3, its word a re-accept. On the word of either HARD STOP, CHANGELOG's line is rewritten under the human class's head, as CLOSE OUT says, and checked in, once, never while a catch-up merge stands open: where the stop fell after the conclude — on a `chose` line or a `fix rounds spent` line, or this item's re-run HARD STOP — or the word is a re-lock, its undo done, at once, before `### CATCH-UP` runs again; where the word is a side ruled on a `locked` line, the merge left open, only once `### CATCH-UP`, resumed from its next path, has concluded that merge and its `### TIER` has closed the block, then before SHOW where that `### TIER` goes on, or, where it stops at tier 3 again, on that stop's word, at once.
5. **SHOW** — `.claude/references/core/gate-close.md` `### SHOW`, its edits the CHANGELOG edit, and its changed-file list from that line's `<head>`, or, on a close by class whose record holds no such line, from the head CHANGELOG left. CLOSE OUT's `--print-read` call runs here, at the head MERGE merges, and its output is kept for RECORD's note.
6. **LIST** — on a delegated or audited class only: one `scripts/hub.py write --root <hub> --tree <this tree> --message <file> --auto-closed <branch> <class> <tier> <YYYY-MM-DD> closing '<title>'` command, with `--main` as the contract says, run from this tree, its message drafted in `.scratch/g2-lite-<changeset>-list/`, the command reading the late overlap from this tree's catch-up record itself, save where a catch-up took the manual row `.claude/references/core/gate-close.md` `## The record` names, whose flags precede the `--auto-closed` as it says: `<class>` RESOLVE's class, `<tier>` `2` where `.claude/references/core/gate-close.md` `### TIER` read tier 2 at this close's catch-up, else `1`, `<YYYY-MM-DD>` CLOSE OUT's date and `<title>` the changeset's title, each `'` in a path or the title written `'\''`. The command writes `## Workflow`'s CLOSE OUT line in its `closing` form, cut within the `board` binding's *STATUS line cap* as CLOSE OUT says, and refuses, writing nothing, where the hub's `memory/STATUS.md` `## Auto-closed` already holds a line under `<branch>`; the table below reads what it prints. Where LIST landed, each later stop's report says that LIST's line stays and nothing merged: HUB READ's `lock`, the hub off the main branch or not clean, a stop at `### CATCH-UP` or `### TIER` on HUB READ's loop, any other refusal of the verb, a failed merge.

| `write` prints | LIST |
|---|---|
| the commit line, exit 0 | LIST's line landed: HUB READ follows |
| `hub.py write:` with a `correct:` line, exit 1 | correct the part it names and re-run, as the contract says; its re-run cap spent, as the last row |
| `hub.py write: edit: --auto-closed <branch>: a line for <branch> already in ## Auto-closed`, exit 1 | HARD STOP, as a human class — nothing merged, and HUB READ runs on after the ruling |
| `hub.py write:` with a `clear:` line, exit 3 | the lock held: reported as the contract says, then HARD STOP, as a human class — nothing merged, and HUB READ runs on after the ruling |
| `hub.py write:` with no `correct:` line, exit 1, or any other output | reported as the contract says, then HARD STOP, as a human class — nothing merged, and HUB READ runs on after the ruling |

7. **HUB READ** — `.claude/references/core/gate-close.md` `### HUB READ`.
8. **MERGE** — `.claude/references/core/gate-close.md` `### MERGE`, with `## Workflow`'s MERGE's word: the G2 ruling on a human class, the slot and RESOLVE's class otherwise.
9. **RECORD** — the `memory/` record of `## Workflow`'s CLOSE OUT, after the merge, in the hub's `memory/`: the record `.claude/references/core/gate-close.md` `## The record` says, one call, its `--note <file>`, then `--close-item <slug> done` per item CLOSE OUT's read, run just before the call, shows `taken <branch>`, and LIST's line, where it landed, rewritten `merged <commit>` by `--auto-closed <branch> <class> <tier> <YYYY-MM-DD> <commit> -`, `<class>` and `<YYYY-MM-DD>` LIST's, `<commit>` the commit MERGE printed, and `<tier>` passed again from the record then, the command, given `--tree`, reading the late overlap again and keeping LIST's title and the same cap, the note naming the merge commit.
10. **KEPT BRIEF** — `.claude/references/core/gate-close.md` `## The kept brief`, in this tree, RECORD's call having landed.
11. **REMOVE** — `.claude/references/core/gate-close.md` `### REMOVE`, with `<lane>` `light`.
