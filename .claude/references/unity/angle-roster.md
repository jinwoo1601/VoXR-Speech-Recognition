Hunt the engine and language traps the generic angles have no reason to know: a `UnityEngine.Object` tested with `??`, `?.` or a cached reference where the lifetime-aware `==` overload was needed; correctness that rests on MonoBehaviour lifecycle order (`Awake` versus `OnEnable` versus `Start`, a teardown that does not undo its setup, two components whose order is assumed rather than declared); a coroutine whose lifetime is not the behaviour's own; a Unity API reached from a task, thread, or async continuation off the main thread; a type moved across an assembly-definition boundary the referencing assembly does not declare; and a mutation written to a returned struct copy and discarded.
